# QTS Public Website Brand Spec

## Design Read

- Mode: Redesign / Preserve
- Audience: Enterprise decision makers and technical stakeholders
- Visual language: light enterprise platform + live operations dashboard + restrained technical blueprint
- Visual variance: 6/10
- Motion intensity: 4/10
- Information density: 6/10
- Asset dependence: 6/10
- Brand fidelity: 9/10

## Identity

QTS makes complex digital systems visible and operable through a unified platform interface. Architecture, integration, security, and operations remain the content spine; live system states, operating flows, and blueprint projects provide the visual proof.

## Asset Rules

- Use local assets and code-native product visuals only.
- Use raster context sparingly; never use stock technology imagery as proof.
- Use blueprint diagrams when they explain a system relationship.
- Keep project SVGs labeled as illustrative architecture artwork.
- Do not imply client proof from partner marks without publication approval.

## Local Visual Assets

- The homepage hero uses the code-native QTS System Center dashboard as its primary product visual.
- `public/images/qts-capability-blueprint.svg`: four-layer capability blueprint for Năng lực.
- `public/images/qts-solution-cybersecurity.svg`: security event, identity, analysis, response flow.
- `public/images/qts-solution-infrastructure.svg`: workload, platform, automation, observability flow.
- `public/images/qts-solution-data-platform.svg`: source, governance, API, decision flow.
- `public/images/qts-intake-topology.svg`: intake path from problem to operations.
- `public/images/projects/*.svg`: original QTS concept artwork for anonymous technical records.

## Protected Contracts

- Routes: `/`, `/nang-luc`, `/giai-phap`, `/du-an`, `/pricing`, `/lien-he`.
- Primary conversion label: `Trao đổi với QTS`.
- No standalone `Liên hệ` navigation item.
- Main navigation: `Platform`, `Solutions`, `Architecture`, `Case Studies`, `Pricing`.
- Trust proof uses supplied metrics rather than unapproved customer logos.
- Security metrics and evidence must remain visibly labeled as model, reference, example, sample, or target data.
- Pricing remains scope-based until QTS supplies approved public rates.
- Existing form field order and API payload remain unchanged.
