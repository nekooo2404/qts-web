# QTS Public Website Brand Spec

## Design Read

- Mode: Redesign / Preserve
- Audience: Enterprise decision makers and technical stakeholders
- Visual language: restrained builder SaaS + information architecture + technical blueprint
- Visual variance: 5/10
- Motion intensity: 4/10
- Information density: 6/10
- Asset dependence: 5/10
- Brand fidelity: 9/10

## Identity

QTS makes complex digital systems visible, inspectable, and operable. Architecture, integration, security, and operations are the recurring visual system.

## Asset Rules

- Use local assets only.
- Use raster context sparingly; never use stock technology imagery as proof.
- Use blueprint diagrams when they explain a system relationship.
- Keep project SVGs labeled as illustrative architecture artwork.
- Do not imply client proof from partner marks without publication approval.

## Local Visual Assets

- `public/images/qts-hero-operations-field.svg`: subtle home hero context field; background only.
- `public/images/qts-capability-blueprint.svg`: four-layer capability blueprint for Năng lực.
- `public/images/qts-solution-cybersecurity.svg`: security event, identity, analysis, response flow.
- `public/images/qts-solution-infrastructure.svg`: workload, platform, automation, observability flow.
- `public/images/qts-solution-data-platform.svg`: source, governance, API, decision flow.
- `public/images/qts-intake-topology.svg`: intake path from problem to operations.
- `public/images/projects/*.svg`: original QTS concept artwork for anonymous technical records.
